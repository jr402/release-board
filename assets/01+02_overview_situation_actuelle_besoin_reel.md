# Overview — Situation actuelle et besoin réel

## 1. Besoin réel

Nous avons besoin d’un **board visuel vivant** pour reviewer les releases mensuelles de figurines, avec :

- une mise à jour quotidienne simple ;
- une lecture immédiate par l’Art Director ;
- une organisation claire par tiers ;
- une visualisation de toute la release en un coup d’œil ;
- la possibilité de zoomer sur un modèle ou un détail ;
- aucune surcharge administrative.

L’objectif n’est pas de créer un nouvel outil de project management.  
L’objectif est de remplacer le board Photoshop actuel par un système plus léger, plus clair, et plus facile à maintenir.

---

## 2. Ce que l’outil doit faire

- Montrer toute la release en un coup d’œil.
- Organiser la release par tier.
- Afficher la dernière version visible de chaque modèle.
- Permettre de reviewer visuellement les modèles.
- Permettre de zoomer sur un modèle ou un détail.
- Montrer rapidement le statut via une couleur.
- Être simple à mettre à jour quotidiennement.
- Servir de support visuel pour l’Art Director et le Technical Supervisor.

---

## 3. Ce que l’outil ne doit pas devenir

- Un project management system.
- Un task tracker complexe.
- Un outil que les artistes doivent administrer.
- Une base de données lourde.
- Un système qui remplace le thread de conversation ou Loom.
- Un outil qui ajoute plus de travail administratif que le process actuel.

---

## 4. Workflow actuel

- Les sculpteurs postent leurs images dans le thread.
- L’assistant / updater récupère les images du jour.
- L’assistant / updater met à jour le board.
- L’Art Director et le Technical Supervisor reviewent le board.
- Le feedback se fait principalement via Loom et le thread.
- La production continue à être gérée normalement.

---

## 5. Problème actuel avec Photoshop

Le board Photoshop fonctionne visuellement, mais :

- le fichier devient lourd ;
- la collaboration est difficile ;
- il peut être compliqué de savoir quelle image est la dernière version ;
- deux personnes ne peuvent pas facilement mettre à jour le board en même temps ;
- les notes et images ne sont pas structurées ;
- la mise à jour quotidienne dépend d’un fichier statique.
